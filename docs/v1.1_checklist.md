- [ ] `low_rna_depth`

- [ ] `weak_link_score`

- [ ] Unit test per reason

## 9. cis_ATAC_score — gene-level aggregation

- [ ] Build `cis_ATAC_score(g) = weighted sum of linked peaks for gene g`
- [ ] Weight options: distance decay, uniform, external link score
- [ ] New parameter: `conditional_mode = "single_peak" | "cis_score"`
- [ ] Output: `rna_after_cis_atac_coef`, `cis_atac_score_method`

## 10. event_id — deterministic

- [ ] `event_id = sha1(peak_id|gene|tf_name|source)[:12]`
- [ ] Same input → same event_id every run
- [ ] Also output `event_key` for human readability

## 11. External links — schema hardening

- [ ] Normalize `link_source`: scenic, scarlink, archr, signac, cicero, user, promoter, distal_250kb
- [ ] Output `link_score` (0–1) and `link_distance` in event_table
- [ ] Validate link_score range in `validate_external_links()`

## 12. from_pseudobulk — full metadata

- [ ] Output `obs` columns: `group_id`, `donor`, `condition`, `cell_type`, `n_cells`, `rna_total_counts`, `atac_total_counts`
- [ ] Drop groups below `min_cells_per_group` and warn
- [ ] Tests for: groupby column missing, condition_col missing, donor_col missing, empty groups, ATAC layer missing, cell order mismatch
